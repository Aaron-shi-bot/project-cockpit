# 项目驾驶舱

项目驾驶舱是一个面向多人团队的项目管理看板，集中查看项目进度、任务、风险、里程碑和资料版本。支持内置账号、邀请加入和项目级权限。

## 项目目录

- `站点/project-cockpit/`：当前 Codex Sites 部署版本，React + Vinext/Cloudflare Workers，使用 D1 和私有 R2。
- `开发/`：可独立运行的本机版本，React + Node.js + SQLite。
- `需求/`、`设计/`：产品需求、视觉规范、设计手册和界面概念图。
- `验证/`：验收计划、测试脚本和已保存的验证记录。
- `选型报告/`：与本项目有关的选型和调研结果。

## 在本机运行

需要 Node.js 24.14 或更新版本。在 `开发` 目录执行：

```powershell
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:4173`，按页面提示创建本机工作区。这个数据库与线上站点相互独立。详细说明见 [本机与云端运行说明](开发/部署说明.md)。

## 在线版本

已部署的 [项目驾驶舱](https://project-cockpit-hub.yonti9474.chatgpt.site/) 可公开打开，项目内容由账号和项目权限保护。Sites 的开发、构建和发布说明见 [Sites 工程](站点/project-cockpit/README.md)。

`站点/project-cockpit/.openai/hosting.json` 记录此项目既有站点标识；如果为其他站点部署，请先创建并绑定属于该站点的配置，避免误用现有线上资源。

仓库不包含生产账号、用户数据、数据库、上传文件、会话、初始化密钥或本机环境文件。GitHub 仓库是源码和设计资料的备份，不是云端数据库及私有文件的完整备份。

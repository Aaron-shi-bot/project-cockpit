# 本机运行与功能验证

日期：2026-10-23。工程根为 `开发/`。本文是运行验证指南；实际通过结果保存在项目根 `验证/验收记录.md`。完整接口见[唯一合同](../../server/contract.md)，完整用例见[验收计划](../../../验证/验收计划.md)。

## Prerequisites

Node.js 24.14或以上及npm；现代浏览器；可写的私有数据目录。首次安装需要依赖来源可访问，已有node_modules可复用。当前没有真实云主机、域名或邮件服务前置要求。

## Setup and Run

在 `开发/` 分别执行：

```powershell
npm ci
npm run build
npm test
npm start
```

启动后打开 `http://127.0.0.1:4173`。默认DATA_DIR为工程的data目录；服务仅在选定HOST/PORT监听，生产静态资源来自dist。开发时可另开终端运行 `npm run dev`，浏览器访问5173，由Vite代理/api到4173；生产验收必须检查构建后的同源入口。

首次页面应引导建立唯一所有者，填写本人姓名、邮箱和至少10位密码；无固定默认账号或密码。初始化后不能再次覆盖所有者。首次工作区为空，演示数据只能由owner显式导入且应明确是样例。

不要在公开、尚未受保护的云入口完成无人看管的首次初始化；最终部署操作见[部署说明](../../部署说明.md)。不得将实际口令写入本文件、命令历史或验收截图。

## US1: 登录、总览、项目、任务风险

1. 创建私有项目，目标、负责人和计划日期完整；默认创建者维护，普通账号未授权时看不到。
2. 创建3项任务，完成1项，检查1/3与33%；取消或软删除后重新核算；无有效任务显示“未拆任务”。
3. 标任务受阻，不填原因应失败；填原因成功后总览受阻。再建独立风险，恢复任务时填处理说明，独立风险继续保留。
4. 两个页面从同一版本保存，后者出现冲突；归档后不能写任务，但能撤权；恢复回归档前状态。
5. 退出、重启服务再登录，项目和已保存记录保留。对应AC-13—26。

## US2: 私有资料和版本

1. 上传小测试文件v1/v2，查看版本记录并分别下载；内容保持一致。
2. 维护者恢复v1，出现新的当前版本，原v1/v2不变；协作成员不能恢复或修改他人资料。
3. 授只读角色可下载历史；撤权后复用旧下载地址和旧页面应被拒绝。
4. 超限、失败或取消上传不出现正式版本；将资料移回收站后不能下载，恢复后重新校验项目权限。对应AC-27—32。

## US3: 邀请、团队、多源权限

1. 所有者/管理员创建邀请，复制链接到另一浏览器会话，受邀者自设密码。界面不能声称邮件已经发出。
2. 重复接受、撤销后接受、失效邀请人接受均失败；匿名预览不返回邀请凭据摘要或无关项目信息。
3. 为成员同时设置直接只读与团队维护来源，移除直接来源后仍有团队权限；移除最后来源后旧页面不能写或下载。
4. 管理员无项目授权时总览无该项目；不能借工作区角色读业务或自我提升。停用账号后旧会话失效，历史作者保留。
5. 常规移除最后维护者被阻止；紧急停用后由owner再次认证、填原因接管；不能失去唯一owner。对应AC-01—12、33。

## Browser and Runtime Checks

- 对照确认VI检查1440px总览、390px手机，以及768px和200%缩放；四项导航、风险、身份色、统计基数、表单错误清楚可读。
- 键盘完成登录、筛选与任务保存，焦点进入弹层并在关闭后回到触发处；手机可撤权。
- 检查网络失败保留草稿，成功提示来自真实服务响应；退出或撤权后不保留可读业务缓存。
- 自动测试使用独立临时数据库，不与开发data混用；不要为重测清空真实工作区。构建和接口通过不能替代浏览器检查。

## Cloud and Recovery Boundary

云端配置使用HTTPS反代、PUBLIC_ORIGIN、SECURE_COOKIE、私有持久卷及实际MAX_FILE_BYTES。[部署说明](../../部署说明.md)给出停服务后一致备份完整DATA_DIR的方式；在独立目录恢复后验证成员、授权、项目与历史文件，再声称恢复通过。

未在真实云端启动、证书、外网登录及备份恢复演练的项保持未验证。保留周期未定不自动永久清理。当前无邮件送达、SSO、杀毒或大文件分块上传接入。

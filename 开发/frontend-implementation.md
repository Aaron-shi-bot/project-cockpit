- 参考：`../设计/概念图/01-项目总览.png`、`02-项目详情.png`、`03-移动总览.png`，以及 `../设计/平台页面/04-团队任务.png`、`05-项目资料.png`、`06-成员与权限.png`。开始实现前已逐张查看。

- 原有轨道品牌标识与线形图标使用统一 SVG 绘制；无需外部字体、图像、CDN 或图标包。

## 实际交互与数据边界

业务数据来自 `/api/state`，写操作对应真实后端接口。没有 localStorage 业务主存储或硬编码用户密码。未初始化时创建所有者；默认空工作区；演示数据只有所有者明确点击并确认后导入，并说明它们是虚构内容。

Cookie 会话为同源，写请求携带 `X-CSRF-Token`。相同 method/path/body 的网络失败或 5xx 重试会复用 `X-Operation-Id`；收到成功响应或明确 4xx 后清除该标识。表单保存期间禁重复提交；服务端已保存但刷新失败时明确报告保存成功，不再次提交原操作。

401/403/404 保存错误会刷新权限并关闭受影响表单。409 保留输入、显示真实业务错误；版本冲突提供“加载最新内容”，用户确认替换草稿后载入新版本。其他保存错误保留输入。表单与任务详情弹窗提供 Esc、焦点约束、关闭后回焦与未保存提醒。桌面并排任务/资料详情属于页面内辅助区，可正常 Tab 进入和离开，不冒充模态弹窗。

项目维护者可创建、编辑、归档、重新打开、删除和导出元数据；完成项目需要闭环检查。协作者只编辑本人负责或本人创建未分配任务的状态/说明；已完成任务重开限维护者。归档/完成项目的业务内容只读。任务阻塞和解除通过任务接口原子维护。

资料支持私有文件上传、鉴权下载、HTTPS 链接、上传新版本、查看历史。历史恢复及删除只展示给维护者；上传者可维护本人资料。成员管理按工作区权限展示，项目授权按维护者展示，并显示直接/团队来源。所有权转移与重设密码需所有者再次认证。

## 验证状态

`npm run build` 已实际通过。浏览器流程与原图对照由主任务统一执行，避免多个智能体同时操纵同一页面；最终验证结果以主任务的浏览器记录为准。本文件不把构建成功当作生产部署完成。

当前不会自动发送邀请邮件；创建后由用户复制链接分享。项目导出为业务元数据，附件仍需鉴权单独下载，完整恢复依赖服务端备份。云服务器外网部署、HTTPS、公开域名和备份由主任务部署步骤处理。

## 浏览器原图对照修订

已对照主任务生成的桌面总览、项目详情、团队任务、成员权限与手机总览截图，使用 view_image 直接与六张现行概念比较。保留原构图、色块、项目身份色、状态标签、表格与底栏，修正了摘要环：六个项目时显示六段，五个进行中为五段白色、一段半透明；详情百分比保持连续环。桌面摘要标题、说明、项目基数和风险文字已提高到参考图的层级。手机总览按原稿先显示两个项目，提供展开/收起全部入口。项目卡片支持长标题自然增高，避免裁掉日期。样例文案差异由后端样例数据修订，界面不硬编码项目或人员。

协作者新建任务时同样不能指定日期、优先级或里程碑，表单禁用这些控件且不发送默认维护字段；已有任务继续仅提交允许修改的状态、说明与阻塞处理字段。

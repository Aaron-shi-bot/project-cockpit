## 建议的最小业务模型

项目包含：名称、目标、负责人、生命周期、当前阶段、健康状态、目标日期、任务、里程碑、资料链接、进展记录。阻塞/风险属于项目，记录原因、影响及下一步。任务和里程碑分别保留计划日期与实际完成日期。

生命周期：待启动 / 进行中 / 已完成 / 已归档；健康状态：正常 / 有风险 / 受阻。两者独立表达，健康状态由风险记录汇总。总览的一列可压缩显示，但筛选不混用。阶段如设计、开发、联调、验收是项目说明，与健康状态不同。

建议任务状态：待开始 / 进行中 / 受阻 / 已完成，另有维护者执行的取消状态。建议项目进度 = 已完成有效任务数 ÷ 有效任务总数；取消或进入回收站的任务不进入分母。完成任务继续计入；项目归档不改变历史进度。一期只做单层任务，检查项不单独计分。无有效任务显示“未拆任务”，不显示0%。不足100%的百分比向下取整，全部完成才显示100%；100%不自动关闭项目。

建议健康状态由该项目未关闭风险项决定：存在阻塞则受阻，否则有风险项则有风险，否则正常；任务标为受阻时同步维护关联阻塞项。更新进展中选择风险/受阻会同时记录原因，恢复正常需关闭现有风险。规则只汇总明确记录，不推测智能分数；人工预计可能延期可以创建风险，系统逾期标签仅按日期计算，不自动改写风险评级。

“进行中项目”包含生命周期进行中的正常、有风险、受阻项目；“需关注项目”统计待启动或进行中且健康为风险或受阻的项目，项目去重；“7天内里程碑”统计今天起至第六天截止、未完成的里程碑，按里程碑ID去重，同日多项分别计数。逾期单独提示，不混入未来七天。时区建议采用使用者设置。

这些口径是本项目建议，不是对飞书运行算法的复述。飞书项目原公式按关联需求数计算，原配置中的空值和复杂延期语义没有实跑验证。[来源与边界](../资料/来源索引.md)

## 一条核心路径

登录并进入有权访问的项目范围 → 打开总览 → 找到需关注项目 → 查看原因、任务和里程碑 → 在角色允许范围内更新进展或任务 → 总览刷新。保存失败保留输入；关闭前提醒未保存内容。所有查询、统计、文件和操作都校验工作区成员状态与项目角色。

## 暂不纳入本轮

复杂审批流、工时填报、预算、人力负荷、多端发布流程、完整CRM和自动同步飞书暂不纳入本轮。实际Sites公开部署已由U-14纳入，须独立验证云端运行，不能沿用本机结果代替。完整权限设计已纳入，不再是暂缓项；任务与资料全局页已在本轮手册展开。匿名外链、跨项目私密字段、任意自定义角色和字段级权限是后续扩展建议，不混入第一版固定角色模型。

## 下一阶段依赖

VI方向与团队范围已确认，最新界面修订仍待用户评价。内置账号与邀请沿用U-07，发布目标按U-08及U-14使用Sites；当前允许公开部署，页面设计验收单独记录。本轮沿用现有官方Spec Kit原则，并以002切片管理部署适配、任务和验收；实施及测试状态以任务与验收记录为准。本机SQLite与私有文件继续留在本机；云端使用独立D1和私有R2，默认文件上限仍为10MiB。审计、历史版本和回收站暂不自动永久清理；发布不等于已具备定时备份、恢复演练或约定容量，须分别给出证据或明确缺口。

本轮云端边界：将既有界面与服务适配到 `站点/project-cockpit`，保留001业务需求、角色与接口口径。空云端库只允许持有高熵一次初始化凭据的人建立首位所有者；初始化未配置或凭据错误时拒绝建立，成功后永久关闭该入口。凭据通过URL片段交给初始化界面，只在首次建立请求头中提交，不进入URL查询、日志、静态包或业务导出；页面读取后移除片段。云端不启用设计演示自动会话，不带入4173/4174库、演示密码、会话和本机上传文件。邀请仍由管理者复制链接交付，不新增公开注册或邮件服务。云端验证需覆盖HTTPS、首次初始化竞争、邀请、完整撤权、私有文件两个版本、并发冲突及冷启动后的持久化；具体用例见[部署验收计划](../开发/specs/002-sites-deployment/acceptance.md)。

本轮实现细则：停用保留尚存授权但立即撤销会话，启用后只恢复尚存来源；已删除授权不复活。协作成员可编辑本人创建且未分配任务时，也能随状态恢复关闭该任务产生的阻塞，不能关闭独立项目风险。邀请为一次性高熵链接，当前由管理员手动交付，不声称验证邮箱所有权或发送邮件。归档保存原生命周期，恢复到已完成时业务仍只读，须显式重开。

## 飞书资料复评的范围控制
